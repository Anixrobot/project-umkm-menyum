# Skema Database Supabase - Terpusat UMKM MenYum (Full Architecture)

Dokumen ini merinci arsitektur database terpusat PostgreSQL di **Supabase** yang menghubungkan 2 aplikasi:
1. **Dashboard Kasir (`dashboard-kasir`)**: Operasional internal, Kasir POS, Pesanan Masuk Real-time, Manajemen Produk & HPP, Buku Kas, dan Akun Login Kasir/Admin.
2. **Website Utama (`website-utama`)**: Etalase publik pembeli (Menu, Keranjang, QRIS) dan **Panel Web CMS** (Kelola Artikel, Moderasi Testimoni, Pengaturan WhatsApp & Medsos).

---

## 1. Pemetaan Tabel & Tanggung Jawab Sistem

| Nama Tabel | Status | Dikelola Dari | Dibaca Oleh | Fungsi Utama |
| :--- | :--- | :--- | :--- | :--- |
| **`admin_users`** | **Baru** | Database / Owner | Dashboard Kasir | Akun login kasir dan admin/owner. |
| **`products`** | Sudah Ada | **Dashboard Kasir** | Website Utama & Kasir | Katalog produk jualan, harga, modal dasar, biaya bahan baku, & stok. |
| **`orders`** | Sudah Ada | Web & Kasir POS | **Dashboard Kasir (Real-time)** | Transaksi pesanan, nama pemesan, metode bayar (QRIS), total, status. |
| **`order_items`** | Sudah Ada | Web & Kasir POS | Dashboard Kasir | Rincian menu, kuantitas, harga, dan **toppings** (Sosis, Bakso, Chili oil). |
| **`cash_flow`** | Sudah Ada | **Dashboard Kasir** | Dashboard Kasir | Buku kas, mutasi masuk/keluar, dan laporan profit bersih harian/bulanan. |
| **`articles`** | **Baru** | **Panel Web CMS** | Website Utama | Artikel & berita edukasi gizi dan kabar dapur. |
| **`reviews`** | **Baru** | Pengunjung & **Panel CMS**| Website Utama | Testimoni pembeli dan fitur moderasi (approve/hapus). |
| **`site_settings`** | **Baru** | **Panel Web CMS** | Website Utama | Kontak dinamis (No WhatsApp, link Instagram, link TikTok, jam operasional, alamat). |

---

## 2. Skrip SQL Editor Supabase (Siap Eksekusi)

Salin seluruh kode SQL di bawah ini, buka dashboard Supabase Anda -> menu **SQL Editor** -> klik **New Query** -> tempelkan dan klik **Run**:

```sql
-- ==========================================================
-- SKRIP SETUP DATABASE TERPUSAT: UMKM MENYUM
-- ==========================================================

-- 1. EXTENSIONS
CREATE EXTENSION IF NOT EXISTS "pgcrypto";

-- 2. TABEL AKUN LOGIN ADMIN & KASIR (BARU)
CREATE TABLE IF NOT EXISTS public.admin_users (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  username TEXT UNIQUE NOT NULL,
  password TEXT NOT NULL,
  name TEXT NOT NULL,
  role TEXT NOT NULL DEFAULT 'kasir' CHECK (role IN ('admin', 'kasir', 'owner')),
  is_active BOOLEAN NOT NULL DEFAULT true,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- 3. TABEL ARTIKEL & BERITA (BARU - DIKELOLA CMS WEB)
CREATE TABLE IF NOT EXISTS public.articles (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title TEXT NOT NULL,
  category TEXT NOT NULL DEFAULT 'Edukasi Gizi',
  read_time TEXT NOT NULL DEFAULT '3 menit baca',
  excerpt TEXT,
  content TEXT NOT NULL,
  image_url TEXT,
  published_date DATE NOT NULL DEFAULT CURRENT_DATE,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()

-- 4. TABEL TESTIMONI & ULASAN PELANGGAN (BARU - DIKELOLA CMS WEB)

  updated_at TIMESTAMPTZ DEFAULT now()
);
ALTER TABLE public.site_videos ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public read site_videos" ON public.site_videos FOR SELECT USING (true);
CREATE POLICY "Public write site_videos" ON public.site_videos FOR ALL USING (true);

ALTER TABLE public.order_items 
ADD COLUMN IF NOT EXISTS toppings TEXT;

ALTER TABLE public.products 
ADD COLUMN IF NOT EXISTS capital_cost NUMERIC DEFAULT 0,
ADD COLUMN IF NOT EXISTS material_cost NUMERIC DEFAULT 0,
ADD COLUMN IF NOT EXISTS is_active BOOLEAN DEFAULT true;

ALTER TABLE public.orders 
ADD COLUMN IF NOT EXISTS queue_number TEXT,
ADD COLUMN IF NOT EXISTS source TEXT DEFAULT 'website',
ADD COLUMN IF NOT EXISTS order_type TEXT DEFAULT 'Dine In',
ADD COLUMN IF NOT EXISTS payment_method TEXT DEFAULT 'Belum Bayar (Kasir)';

-- 7. AKTIFKAN SUPABASE REALTIME REPLICATION UNTUK ORDERS & PRODUCTS
DO $$
BEGIN
  IF NOT EXISTS (
    SELECT 1 FROM pg_publication_tables 
    WHERE pubname = 'supabase_realtime' AND tablename = 'orders'
  ) THEN
    ALTER PUBLICATION supabase_realtime ADD TABLE public.orders;
  END IF;
  
  IF NOT EXISTS (
    SELECT 1 FROM pg_publication_tables 
    WHERE pubname = 'supabase_realtime' AND tablename = 'products'
  ) THEN
    ALTER PUBLICATION supabase_realtime ADD TABLE public.products;
  END IF;
END $$;

-- 8. BERIKAN HAK AKSES QUERY KE ANON DAN AUTHENTICATED
GRANT ALL ON ALL TABLES IN SCHEMA public TO anon, authenticated;
GRANT ALL ON ALL SEQUENCES IN SCHEMA public TO anon, authenticated;
```
